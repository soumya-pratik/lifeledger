# Seed category Rent renamed to House Emi

- **Date:** 2026-09-01
- **Type:** decision
- **Status:** shipped

## Summary

The default housing category is **House Emi**, not Rent. Existing Dexie rows named Rent are renamed on load; if House Emi already exists on the ledger, spends and proposals on Rent are moved and the Rent row is archived.

## What changed

- [`src/shared/domain/ledger.ts`](../../src/shared/domain/ledger.ts) — `DEFAULT_CATEGORIES`.
- [`src/features/expenses/api.ts`](../../src/features/expenses/api.ts) — `renameRentToHouseEmi`, called from `listCategories` and workspace boot.
- [`src/features/imports/parseCsv.ts`](../../src/features/imports/parseCsv.ts) — narration needles still include `rent`, mapped to name House Emi (D13: map by name then id).
- Docs: [`../DECISIONS.md`](../DECISIONS.md) D13 seed list, [`../08_Data_Models.md`](../08_Data_Models.md), [`../03_Features.md`](../03_Features.md).

## Why / rejected

Product language matches EMI, not rent. Category **ids** stay stable when only the name changes.
